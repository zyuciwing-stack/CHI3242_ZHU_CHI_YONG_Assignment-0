## 分析方法

關鍵稱謂頻次統計（儒生／通人／文人／鴻儒）＋KWIC 上下文檢索（前後各約 20 字）＋全文段落編號與高亮回查：

1. 以單趟正則掃描全文，逐一記錄每次命中的段落編號、段內字位、前後各約 20 字語境，並在全文中高亮標記、賦予錨點。
2. 所有次數與條數由程式計算，腳本內不寫死預期值；腳本在結束前核對「KWIC 條數＝字串計數」，不一致即中止。
3. 網頁包含：研究問題、頻次表與長條圖、可搜尋的語境列表（附段落跳轉）、帶段落編號與稱謂高亮的完整原文、簡短解讀（附原文依據）、方法限制。

**方法限制**：固定字串檢索只保證列出字串命中，不宣稱自動保證人物或語義分析沒有遺漏；頻次僅描述篇內提及多寡，價值高下須由原文論證（定義句、比較句、比喻段）判斷；單字「文」歧義大（文王、文軒、文墨等），未納入統計。
